# BiesiorNator
## Bug Reports and Feature Requests

BiesiorNator is an extensive interactive catalogue of guitar chords and voicings, combined with an advanced chord progression editor. Explore chord shapes, arrange progressions, listen to them and prepare them for practice or printing. Cloud synchronisation keeps your library available across devices, while public links let you share your progressions with others.

**[Open BiesiorNator](https://nator.biesior.com)**

## About this repository

This repository is the public issue tracker for BiesiorNator. It does not contain the application source code.

Use **Issues** to report bugs or suggest improvements. Before opening a new issue, please check existing reports.

For bug reports, include:

- Application version
- Browser and operating system
- Steps to reproduce the problem
- Expected and actual behaviour
- Screenshots, if helpful

Do not include passwords, access tokens or private cloud links. For security-sensitive reports, contact **biesior@gmail.com**.
